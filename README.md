# elijxhraz

Personal portfolio website built with Express.js + custom HTML/CSS.

## Setup

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000).

## Images

Place your images inside `public/images/`:

| File | Purpose |
|------|---------|
| `background.gif` | Full-page animated background |
| `circle.png` | Profile picture (shown as circle) |

## Stack

- **Backend**: Node.js + Express
- **Frontend**: Custom HTML5 / CSS3 (glassmorphism design)
- **No frameworks** — pure vanilla JS
